# UI-UX-Experiment 2

##  Design a Basic Mobile and Web Layout for an Existing Case Study

### Aim:
To design basic mobile and web layouts for an existing case study by applying Gestalt principles, incorporating UI elements and design patterns, developing interaction behaviors and usability principles, and creating a brand logo using Canva.

### Algorithm:

**Step 1: Select an Existing Case Study**
- Select an existing application or website for the design.
- Example: Food Delivery Application.
- Identify its target users and basic requirements.

**Step 2: Apply Gestalt Principles**
- **Proximity:** Group related elements together.
- **Similarity:** Use similar colors, shapes and styles for related elements.
- **Closure:** Use visual elements that allow users to identify incomplete shapes.
- **Continuity:** Arrange elements in a way that guides the user's eyes naturally.
- **Figure and Ground:** Maintain clear contrast between foreground elements and background.

**Step 3: Incorporate UI Elements and Design Patterns**
- Add buttons, icons, images, text fields and navigation menus.
- Use familiar design patterns such as search bars, cards, menus and navigation bars.
- Maintain consistent colors, fonts and spacing.

**Step 4: Develop Mobile and Web Layouts**
- Create a mobile layout with a simple and responsive interface.
- Create a web layout with organized sections and clear navigation.
- Ensure that both layouts provide a consistent user experience.

**Step 5: Implement Interaction Behaviors and Usability Principles**
- Add clickable buttons and navigation links.
- Provide feedback when users perform actions.
- Ensure easy navigation and readability.
- Maintain consistency and accessibility.
- Minimize the number of steps required to complete tasks.

**Step 6: Create a Brand Logo Using Canva**
- Open Canva and select a logo template.
- Choose suitable colors, fonts and symbols.
- Design a logo that represents the brand identity.
- Maintain simplicity, readability and consistency.
- Export the logo in PNG format.

**Step 7: Finalize the Design**
- Combine the logo with the mobile and web layouts.
- Review the designs for consistency and usability.
- Capture screenshots and save them for the lab report.
